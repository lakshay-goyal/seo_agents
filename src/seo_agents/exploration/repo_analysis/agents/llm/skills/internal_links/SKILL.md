---
name: explore-seo-internal-links
description: Extract source-backed destinations and accessible anchor labels using the repository's actual router.
---

Inspect router configuration, link wrappers and framework navigation components,
including to/href/routerLink bindings, local data-driven menus, layouts and includes.
Resolve literal destinations and enumerable local parameters; retain the original
href. Resolve relative URLs against each page route without guessing an origin.

Capture anchor text and accessible name from visible text, aria-label or linked
image alt when observed, plus rel and target. Distinguish internal pages, resources,
actions, absolute URLs, hashes and query links. Unresolved route objects, redirects,
click handlers and dynamic targets require explicit coverage gaps. Use source IDs
shared with content link_refs, including source columns for same-line anchors.
