---
name: explore-seo-media
description: Inventory page media, alt text, responsive attributes and measured local assets across frontend frameworks.
---

Inspect native image/video/audio/source/track/iframe tags, framework image
components, asset imports, picture sources, data-driven media and shared layouts.
Map local sources to captured asset paths where defensible. Preserve empty alt,
missing alt and unresolved bindings distinctly. Capture dimensions, srcset/sizes,
loading, priority/preload and relevant responsive declarations with evidence.

Use only the assets input for bytes and intrinsic dimensions; unknown remote or
optimized sizes stay null. Record declared and measured dimensions separately.
The 200 KiB source-size threshold is a review heuristic. Do not invent framework
loading defaults without evidence. Keep unused assets separate from page usage.
Use source IDs shared with content media_refs and enumerate unresolved sources.
