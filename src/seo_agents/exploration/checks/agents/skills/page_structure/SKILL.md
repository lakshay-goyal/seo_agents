description: Extract route-specific heading hierarchy and semantic landmarks across frontend templates.
---

Discover real page entries and shared shells from the repository's routing model.
Follow heading components, named slots, includes, layouts and literal heading-level
props where resolvable. Record h1 through h6 with text, source position and section
context in composition order. Distinguish HTML headings from typography classes.

Inventory main/article/section/nav/header/footer/aside landmarks with source
evidence. Do not fabricate a hierarchy from font size or CSS. Flag runtime heading
levels, unresolved components, conditional branches and composition order as gaps;
multiple H1s and skipped levels are downstream review candidates, not judgments here.
