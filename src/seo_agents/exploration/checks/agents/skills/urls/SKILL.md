---
name: explore-seo-urls
description: Discover route templates, dynamic URL patterns and query navigation from framework routing evidence.
---

Inspect manifests/config, filesystem routes, explicit router declarations, nested
routes, locales, base paths and static-generation data in this repository. Map
public routes to source entry templates; shared components are not independent
pages. Handle index routes, route groups and framework-specific dynamic/catch-all
syntax according to observed conventions. Enumerate literal route data if present.

Retain unresolved dynamic patterns as templates rather than inventing slugs or
claiming complete URL coverage. Include route depth and source-backed query links.
Record aliases, redirects, unknown base/origin and runtime routes as limitations
unless resolved from source. Keep route identities consistent across all reports.
